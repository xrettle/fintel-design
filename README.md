# fintel-design
A compilation of as many agentic design skills into a single file, which can be used universally in any app to design beautiful, amazing web UI's.
# How to use
Go the the `fintel-design-skill` file, copy or download it, then give it to an AI (eg. Claude, ChatGPT, Gemini, Grok, Perplexity, Mistral, etc), use this prompt `The following document (the fintel-design-skill file) is your design system. It defines your standards for all UI work -- typography, color, spacing, animation, accessibility, and component behavior. Read it fully and apply it to everything you do.`. I personally have better results not one-shotting apps, but first letting the agent build the app and then I attach this prompt: "Redo the UI of this app in a [put whatever design style you want here]. Do not change any functionality, logic, or data — only the visual layer.



I have attached the fintel-design-skill file. This file is a compiled collection of named UI and design skills for coding agents. It contains a navigation guide at the top — read that first so you know which skills apply to this task. Use as many skills as possible." after to get better results.
